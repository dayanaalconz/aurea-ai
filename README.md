# AUREA AI

**Agentic Financial Intelligence Platform**

*Financial Intelligence, Reimagined.*

AUREA AI is an end-to-end financial intelligence platform designed to combine
deterministic financial analytics with a controlled, tool-using AI copilot.

## Project Status

🚧 Milestone 01 — Project Foundation

## Engineering Principles

- Deterministic and testable financial calculations
- Clear separation between financial analytics and language models
- Controlled AI tool usage
- Evidence-based financial explanations
- Modular and maintainable architecture
- Systematic testing and evaluation

## Technology Stack
